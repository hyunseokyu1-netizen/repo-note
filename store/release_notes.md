### English (en-US)

```
v1.0.2 update

• Drag to move — long-press a file and drag it into any folder
  (drop it on the zone at the bottom to move it to the root folder)
• Move folders — long-press a folder and use "Move to folder…"
• The file menu (rename, delete, …) moved to the ⋮ button on the right
```

## v1.0.0 (2026-07-17) — 첫 출시

### 한국어 (ko-KR)

```
RepoNote 첫 출시! 🎉

GitHub 저장소를 메모장처럼 쓰는 마크다운 메모 앱입니다.

• GitHub Fine-grained Token으로 안전하게 연결
• 폴더 트리로 노트 탐색 (.obsidian 자동 숨김)
• 마크다운 편집 + 미리보기
• 쓰기만 하면 자동 저장, 입력이 멈추면 자동 커밋
• 오프라인에서도 작성 — 연결되면 자동 업로드
• 충돌이 나면 덮어쓰지 않고 두 버전을 비교해 선택
• 파일 생성·이름 변경·삭제·검색
• 다크 모드, 한국어/영어 지원

Obsidian Vault를 GitHub에 두고 쓰신다면, 폰에서 그대로 이어서 쓰세요.
```

### English (en-US)

```
RepoNote is here! 🎉

A markdown note app that turns your GitHub repo into a notepad.

• Secure connection with a fine-grained token
• Folder tree browsing (.obsidian hidden)
• Markdown editing + preview
• Auto-save as you type, auto-commit when you stop
• Write offline — syncs when you're back online
• Conflicts are never overwritten: compare and choose
• Create, rename, delete, search notes
• Dark mode, English & Korean

Keep your Obsidian vault on GitHub? Pick up right where you left off.
```
