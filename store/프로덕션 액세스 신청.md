앱 정보
앱의 주요 대상은 누구인가요?
>>
RepoNote 의 주요 대상은 GitHub 저장소를 개인 메모장이나 마크다운 노트 관리용으로 사용하는 개발자, 기술 문서 작성자, 그리고 Obsidian 등 마크다운 기반 노트 앱을 쓰는 사용자입니다. 특히 여러 기기에서 GitHub 저장소 기반 노트를 동기화하며 사용하고 싶은 모바일 사용자를 중심으로 설계되었습니다.

>>
RepoNote 는 GitHub 저장소를 실시간 마크다운 메모장으로 바꿔줍니다. 사용자는 GitHub Fine-grained Token 으로 안전하게 연결해, 폴더 트리로 노트를 탐색하고 마크다운을 편집·미리보기할 수 있습니다. 자동 저장 및 자동 커밋으로 별도 저장 없이 쓰고, 오프라인에서도 작성한 뒤 연결되면 자동 동기화됩니다. 충돌 시 두 버전을 비교해 선택할 수 있어 안전하게 관리할 수 있으며, Obsidian Vaults 를 GitHub 에 두고 쓰는 사용자는 모바일에서 같은 노트를 이어 쓸 수 있습니다.

비공개 테스트에서 알게 된 내용을 바탕으로 앱을 어떻게 변경했나요?
>>
비공개 테스트에서 테스터들이 “전체 선택 시 잘라내기/복사 메뉴가 키보드에 가려 불편하다”, “편집 화면 마지막 줄과 키보드 사이 여백이 어색하다”는 피드백을 주었고, 전체 선택 시 메뉴 위치를 화면 상단으로 변경하고 편집기 하단 여백을 자연스럽게 조정했습니다. 또한 위키링크([[노트 이름]]) 기능이 실제 사용 시 유용하다는 점을 확인해 보기 모드에서 탭해 바로 이동하는 칩 UI 로 개선했으며, 파일 드래그 이동과 폴더 이동 기능을 추가해 실제 사용자가 여러 노트를 정리하는 시나리오를 더 잘 지원하도록 변경했습니다.


앱이 프로덕션용으로 준비되었다고 어떻게 판단했나요?
>>
비공개 테스트 기간 중 12명 이상의 테스터가 14일간 지속적으로 참여했으며, 주요 기능(GitHub 연동, 저장소 동기화, 마크다운 편집·미리보기, 자동 저장·커밋, 오프라인 작성, 충돌 처리 등)에 대한 테스트가 모두 완료되었습니다. 사전 출시 보고서에서 ANR 및 충돌이 없었고, 테스터 피드백을 반영해 UI/UX 를 개선한 v1.0.4 까지 안정적으로 동작하는 것을 확인했습니다. 다양한 해상도의 기기에서 사용자 흐름이 자연스럽고, 실제 사용 환경에서도 문제없이 이용 가능하다고 판단해 프로덕션용으로 준비되었다고 보았습니다.
