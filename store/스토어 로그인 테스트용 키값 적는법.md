RepoNote는 GitHub Token을 등록해야만 모든 기능을 쓸 수 있으므로 "예 (앱에 제한된 부분 있음)" 에 해당합니다 ("계정 로그인 세부정보" 항목). "아니요"로 냈다가 심사에서 로그인 화면을 만나면 반려됩니다.

"예" 선택 후 나오는 안내 추가(Add instructions) 폼은 이렇게 채우면 됩니다:

┌────────────────────┬────────────────────────────────────────────────────────────┐
│        필드        │                           입력값                           │
├────────────────────┼────────────────────────────────────────────────────────────┤
│ 안내 이름          │ GitHub token login                                         │
├────────────────────┼────────────────────────────────────────────────────────────┤
│ 사용자 이름/이메일 │ (심사용 GitHub 계정 아이디)                                │
├────────────────────┼────────────────────────────────────────────────────────────┤
│ 비밀번호           │ (심사용 계정 비밀번호 — 또는 "not required, token below" ) │
├────────────────────┼────────────────────────────────────────────────────────────┤
│ 기타 정보          │ 아래 템플릿                                                │
└────────────────────┴────────────────────────────────────────────────────────────┘

기타 정보 템플릿:



This app does not use username/password login. It authenticates with a
GitHub personal access token only.

1. On the first screen, paste this token into the "GitHub Token" field:
   github_pat_XXXX... (심사용 토큰)
2. Tap "Verify connection".
3. Select repository "reponote-review-demo" → branch "main" → tap
   "Use repository root (/) as Vault".
4. All features (browse, edit, auto-commit, sync, conflict handling)
   are now testable.

The token has Contents read/write access to a single dedicated test
repository only. It contains no personal data.
