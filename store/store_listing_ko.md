# RepoNote — 스토어 등록 문구 (한국어)

## 앱 이름 (30자 이내)
RepoNote - GitHub 마크다운 메모장

## 간단한 설명 (80자 이내)
GitHub 저장소를 메모장처럼. Obsidian Vault를 폰에서 열고, 쓰고, 자동 커밋하세요.

## 자세한 설명 (4000자 이내)
RepoNote는 GitHub 저장소에 보관한 Markdown 문서를 모바일에서 일반 메모장처럼 빠르게 쓰고 자동으로 동기화하는 개인용 메모 앱입니다.

Obsidian Vault를 GitHub에 올려 두셨나요? 이제 폰에서도 같은 노트를 바로 열어 이어서 쓸 수 있습니다. 복잡한 Git 명령은 몰라도 됩니다 — 입력을 멈추면 앱이 알아서 커밋합니다.

■ 이런 분께 좋아요
• Obsidian Vault를 GitHub로 백업/동기화해서 쓰는 분
• 개발 노트, TIL, 블로그 초안을 GitHub 저장소에 모아 두는 분
• 출퇴근길에 떠오른 아이디어를 바로 저장소에 남기고 싶은 분

■ 주요 기능
• GitHub Fine-grained Token으로 안전하게 연결 — 메모 저장소에만 접근
• 저장소·브랜치·Vault 폴더 선택 후 바로 사용
• 폴더 접기/펼치기 트리로 한눈에 탐색 (.obsidian 폴더 자동 숨김)
• 마크다운 편집 + 미리보기 (체크리스트, 인용, 코드 블록 렌더링)
• 로컬 자동 저장: 입력하는 즉시 기기에 저장되어 유실 걱정 없음
• 자동 커밋: 입력이 멈추면 5초 뒤 GitHub에 자동 반영 (시간 조절 가능)
• 오프라인 지원: 인터넷이 없어도 쓰고, 연결되면 자동 업로드
• 충돌 감지: 서버 파일이 바뀌면 덮어쓰지 않고 두 버전을 비교해 선택
• 새 메모·새 폴더·이름 변경·삭제·검색
• 다크 모드, 한국어/영어 지원

■ Obsidian 호환
YAML Front Matter, [[위키링크]], 태그를 그대로 보존합니다. 문서를 임의로 재포맷하지 않습니다.

■ 보안
• Token은 기기의 보안 저장소(Keystore)에만 저장됩니다
• 모든 통신은 HTTPS로만 이루어집니다
• Token과 문서 내용은 어떤 로그나 외부 서비스로도 전송되지 않습니다

■ 사용 준비물
GitHub 계정과 Fine-grained Personal Access Token(Contents 읽기/쓰기 권한)이 필요합니다. 앱 안에 발급 안내 링크가 있습니다.
