## 3. 데이터 보안 (Data safety) 섹션 답안 ★

> 근거: 이 앱은 개발자 서버가 없고, 광고·분석·크래시 리포트 SDK도 없다.
> 모든 데이터는 ① 기기 내부, ② 사용자가 직접 지정한 본인 GitHub 저장소에만 존재한다.
> GitHub API 통신은 사용자가 시작한 동작(연결·저장)에 의한 것으로,
> 개발자는 어떤 데이터에도 접근할 수 없다.

### Q1. 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요?
→ **아니요 (No)**

- Google 정의상 "수집"은 개발자(또는 개발자를 대신하는 주체)에게 기기 밖으로
  전송되는 것을 말합니다. 이 앱의 유일한 전송은 **사용자 본인이 등록한 GitHub
  계정으로, 사용자가 시작한 저장/동기화 동작**에 의한 것이며 개발자에게는 아무것도
  전송되지 않습니다.
- 토큰·노트·설정은 기기에만 저장 → "기기 내 처리"에 해당.

### Q2. 모든 사용자 데이터가 전송 중에 암호화되나요?
(Q1을 "아니요"로 답하면 표시되지 않을 수 있음. 표시되면)
→ **예** (모든 통신은 HTTPS/TLS)

### Q3. 사용자가 데이터 삭제를 요청할 수 있나요?
(표시되면) → **예** — 앱 내 로그아웃으로 즉시 전체 삭제

### 결과 스토어 표시
"데이터가 수집되지 않음 / 제3자와 공유되지 않음"으로 표시됩니다.

### (참고) 심사에서 이의가 제기될 경우의 대안 선언
드물게 GitHub 전송을 "수집"으로 해석하라는 피드백을 받으면 아래처럼 선언:

| 데이터 유형 | 수집/공유 | 목적 | 암호화 | 삭제 요청 |
|---|---|---|---|---|
| 앱 활동 > 기타 사용자 생성 콘텐츠 (노트 본문) | 수집 (개발자 접근 불가) | 앱 기능 | 전송 중 암호화 | 예 |
| 사용자 ID (GitHub 사용자명) | 수집 | 앱 기능, 계정 관리 | 전송 중 암호화 | 예 |
